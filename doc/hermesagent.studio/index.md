# Hermes Agent Self-Hosted AI Agent Framework

Maintained by HermesAgent Studio - self-improving - cross-platform - open source

[Quickstart](guide/quickstart.md)

[GitHub](https://github.com/clauxel/Hermes-Agent)

## Self-Learning

Automatically turns repeated workflows into reusable skills, builds long-term memory, and keeps user context across sessions.

## 14+ Messaging Platforms

Deploy the same agent to Telegram, Discord, Slack, WhatsApp, Signal, WeCom, Feishu, DingTalk, and more.

## Fully Self-Hosted

Keep your data under your own control with support for Docker, SSH, local execution, Singularity, Modal, and other backends.

## Model-Agnostic

Switch between OpenAI, Claude, Gemini, DeepSeek, Qwen, Ollama, and 200+ models without changing your workflows.

## 47 Built-In Tools

Use web search, terminal execution, browser automation, image generation, speech recognition, code execution, and more out of the box.

## MCP Support

Hermes Agent can consume external MCP servers as a client and expose its own capabilities as an MCP server for IDEs and other tools.

## Why Hermes Agent?

Hermes Agent is an open-source, self-hosted AI agent framework maintained by [HermesAgent Studio](https://hermesagent.studio/). It is released under the MIT License, and its source code is available on [GitHub](https://github.com/clauxel/Hermes-Agent).

Unlike one-off chat assistants, Hermes Agent is designed to improve over time. It learns from conversations, extracts reusable skills, updates memory, and becomes more useful the longer you work with it.

### Core Advantages

| Feature | What it gives you |

| Self-learning loop | Automatically extracts skills and builds a persistent user profile |
| Multi-platform gateway | One configuration for 14+ messaging platforms |
